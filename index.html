Guias de tags HTML do 3º Ano

Aula prática: 25 de Maio de 2026

1. Semântica e Formatação

O HTML não é linguagem de programação, mas de marcação.

Usamos a tag <abbr> para siglas como CSS.

Para dar ênfase em uma palavra, usamos a tag <em>

Importante: Sempre use tags semânticas!

2. Citações e Referências

Uma frase famosa no mundo dev:

"Primeiro, resolva o problema. Depois escreva o código."

3. Estrutura Moderna

Sites modernos usam HTML semântico para melhorar acessibilidade e organização.

Tags como <header>, <main> e <footer> ajudam na estrutura do projeto.
